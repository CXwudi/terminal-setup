# Further PowerShell Setup

Follow [PowerShell - Setup](./PowerShell%20-%20Setup.md) first, then choose the layout that matches where you want the tooling and data to live:

- [C drive installation](./PowerShell%20-%20Further%20Setup%20-%20C%20Drive.md): default Windows user directories, with portable mise and personal scripts in `%USERPROFILE%\.local\bin`.
- [D drive installation](./PowerShell%20-%20Further%20Setup%20-%20D%20Drive.md): portable mise and scripts in `D:\local\bin`, with tool data under `D:\local`.

Both guides use the same [Windows mise configuration](./mise-configs/config.windows.toml) and install tools from that file.
